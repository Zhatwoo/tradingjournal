# Forex Calculation Examples

## How the New System Works

The updated trading journal now uses accurate forex profit calculations based on:

1. **Account Type** (Standard, Mini, Micro)
2. **Currency Pair** (including XAUUSD, JPY pairs)
3. **Lot Size**
4. **Trade Direction** (BUY/SELL)
5. **Pip Values** specific to each pair

## Example Calculations

### XAUUSD (Gold) - Standard Account
- **Entry**: $1800.00
- **Exit**: $1810.00  
- **Lot Size**: 1.0
- **Direction**: BUY
- **Pip Size**: 0.01
- **Pip Value**: $1.00 per pip
- **Pips Moved**: 100 pips (10.00 / 0.01)
- **Profit**: $100.00 (100 pips × $1.00)

### EURJPY - Mini Account
- **Entry**: 150.00
- **Exit**: 150.50
- **Lot Size**: 0.1
- **Direction**: BUY
- **Pip Size**: 0.01
- **Pip Value**: ~$0.67 per pip (for mini account)
- **Pips Moved**: 50 pips (0.50 / 0.01)
- **Profit**: ~$33.50 (50 pips × $0.67)

### GBPJPY - Micro Account
- **Entry**: 180.00
- **Exit**: 179.50
- **Lot Size**: 0.01
- **Direction**: SELL
- **Pip Size**: 0.01
- **Pip Value**: ~$0.56 per pip (for micro account)
- **Pips Moved**: 50 pips (0.50 / 0.01)
- **Profit**: ~$28.00 (50 pips × $0.56)

## Key Features Added

1. **Account Type Selection**: Choose between Standard, Mini, or Micro accounts
2. **Trade Direction**: Specify BUY or SELL
3. **Currency Pair Dropdown**: Organized by categories (Major Pairs, JPY Pairs, Commodities)
4. **Real-time Calculations**: Profit updates automatically as you type
5. **Risk Management**: Stop loss pip input with risk amount calculation
6. **Accurate Pip Values**: Different pip values for different pairs and account types
